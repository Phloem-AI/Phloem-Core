# Phloem

AI E2E testing for your software. Use this harness through CLI, plug in your own LLM, and leave your software on auto-testing. 

## Get Started

Install phloem through **npm**, paste in your LLM API Key. Configure the environment following the setup wizard guide.

Phloem then runs locally on your computer, navigates your software, writes tests, and runs them. 

You can also clone this repository and set it up locally for the same functionality.
